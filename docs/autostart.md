# 自动启动

Windows 软件用户：在管理窗口“连接与启动”勾选登录 Windows 后自动启动并保存。下一次登录当前用户会在后台启动 Bridge 和 Tunnel；Tunnel 等待本机 Bridge、所配置代理和密钥就绪。详见 [使用手册](user-guide.md)。

关闭窗口不停止后台。首页“停止”只停止该软件实例拥有的服务；不结束其他终端或未知进程。开机不会自动发送新需求；只在已启用对话中按你的需求工作。

凭据使用当前用户 DPAPI 加密，启动项不保存明文。日志为用户数据目录下 `autostart/startup.log`，按大小轮换。

## 旧版源码兼容

`scripts/install-autostart.ps1`、`scripts/autostart.py` 继续支持原有源码部署，启动依赖原项目中的 `.venv` 和 `.tools`。迁移到软件时先在管理窗口显式导入，再停止旧后台并关闭旧启动项，最后保存软件的新启动设置。不要同时运行两个版本占用相同端口。
