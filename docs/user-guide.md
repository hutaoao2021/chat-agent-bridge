# Chat Agent Bridge 使用手册

它把普通 ChatGPT 对话连接到你授权的电脑项目。Windows 软件管理本地 Bridge、Tunnel、设置和诊断；浏览器扩展管理对话绑定、续接和命令审批。

## 日常使用

首次完成 [新电脑安装](new-computer.md) 后，在软件“连接”保存“登录 Windows 后自动启动”。以后开机登录后会在后台启动服务，不需要两个终端。管理窗口关掉后后台继续运行。

浏览器中，一个对话只需点一次“启用当前对话”。它会记住该对话的工作模式。以后直接发送工作需求，扩展自动准备一次性任务绑定。其他对话保持普通聊天。暂停续接后，可以再次启用；停止任务会结束当前任务。

扩展显示“已连接”时，配对码输入框为空是正常的，不需要每次重新输入。扩展与本机之间的配对凭据有有效期；过期、解除配对、更换 Windows 用户或新电脑后才需要重新配对。扩展更新后刷新已打开的 ChatGPT 页面一次。

## 工作流程

1. 你在已启用对话发送需求，扩展附加任务绑定信息。
2. ChatGPT 通过 Tunnel 调用 Bridge，建立任务并读取已授权工作区。
3. 模型修改文件、保存检查点；需要运行命令时，扩展显示实际命令，由你批准后执行。
4. 本轮结束但任务未完成时，扩展根据检查点发送续接信息；遇到额度、未知发送结果、人工输入或续接上限会暂停。
5. 任务完成时保存结果并结束。`completed` 后续接暂停是正常状态。

任务绑定码和浏览器配对码用途不同，扩展会自动准备任务绑定码。不要把本机配对码或 API key 发到对话。

## 设置

“工作区”中选择实际项目目录。读取默认可用；文件写入、命令、Git 写入分别授权。命令以你的 Windows 用户身份执行；工作目录不是系统隔离沙箱。首次建议使用测试目录。

“连接”填写 Tunnel ID、Tunnel API key、可选本地 HTTP 代理和端口。密钥框留空会保留已保存密钥，离线时也能保存设置。更改端口或项目后重启后台生效；扩展控制地址也应匹配新的控制端口。

密钥使用当前 Windows 用户的 DPAPI 加密；不放入项目文件、日志或诊断。Git、SSH、项目自身的 Python/Node 等工具仍由项目使用的电脑提供，软件自带的 Python 用于 Bridge 自身。

## 迁移与卸载

首页“导入旧版”选择旧项目目录，复制配置、任务记录和当前用户可解密的密钥。目标已有设置或数据库时拒绝覆盖。导入后核对项目位置与代理，然后停止旧版后台启动，再启用软件的新后台启动；两个版本同时占用端口会报告冲突。

Windows 应用列表可以卸载。默认保留用户设置和记录；卸载时可明确选择删除软件数据。任何工作区文件都不随软件卸载删除。换电脑应重新添加当地工作区、密钥和浏览器配对，不能直接复制 DPAPI 文件。

数据目录：`%LOCALAPPDATA%\ChatAgentBridge\data`。安装目录：`%LOCALAPPDATA%\ChatAgentBridge\app`。它不更改全局 PATH，不要求管理员权限。
