# Chat Agent Bridge 使用手册

它把普通 ChatGPT 对话连接到你授权的电脑项目。Windows 软件管理本地 Bridge、Tunnel、设置和诊断；浏览器扩展管理对话绑定、续接和命令审批。

## 日常使用

首次完成 [新电脑安装](new-computer.md) 后，在软件“连接”勾选“登录当前 Windows 用户后自动运行”并保存。此设置在当前用户登录后启动后台监督程序；Bridge 和 Tunnel 能否就绪还取决于配置、网络与权限。关闭管理窗口不会停止已运行的服务。

浏览器中，一个对话只需点一次“启用当前对话”。它会记住该对话的工作模式。以后直接发送工作需求，扩展自动准备一次性任务绑定。其他对话保持普通聊天。扩展“暂停”会关闭该对话工作模式，不取消正在执行的命令；继续工作前需再次启用。“停止任务”会把任务记录标记为取消并请求取消相关命令；必须核对取消结果，记录取消不等于所有本地或远端进程已退出。

扩展显示本机配对有效，表示本次向本机 Bridge 的授权请求通过；不代表 Tunnel 已连通或 ChatGPT 已接入。配对成功后配对码框为空正常。配对码有效 5 分钟、限一次使用；换取的浏览器配对凭据有效 30 天。过期、撤销、浏览器数据丢失、更换用户或新电脑时需重新配对。扩展更新后刷新已打开的 ChatGPT 页面一次。

桌面软件“停止”会停止自身服务，持久后台命令可能继续运行，不会自动取消。要取消命令，需保持或重新启动服务，在扩展使用“停止任务”并核对结果。关机或注销可能终止进程，软件不保证随后自动恢复未结束命令。

## 工作流程

1. 你在已启用对话发送需求，扩展附加任务绑定信息。
2. ChatGPT 通过 Tunnel 调用 Bridge，建立任务并读取已授权工作区。
3. ChatGPT 根据需求和工作区权限调用读写工具、保存检查点；请求执行命令时，扩展显示审批摘要，由你批准后执行。
4. 页面、服务和续接资格满足条件时，扩展发送续接信息，要求模型读取最新检查点；遇到额度、未知发送结果、人工输入或续接上限会暂停。
5. `completed` 表示 Bridge 任务记录已被标记完成；修改和测试是否满足需求需查看实际工具结果。任务完成后不再为该任务自动续接。

任务绑定码和浏览器配对码用途不同，扩展会自动准备任务绑定码。不要把本机配对码或 API key 发到对话。

## 设置

“工作区”中选择实际项目目录。读取默认可用；文件写入、命令、Git 写入分别授权。本机命令以当前 Windows 用户身份执行；SSH 命令以目标 SSH 账号身份执行。工作目录不是系统隔离沙箱。首次建议使用测试目录。

“连接”填写 Tunnel ID、Tunnel API key、可选本地 HTTP 代理和端口。密钥框留空会保留已保存密钥，离线时也能保存设置。更改端口或项目后重启后台生效；扩展控制地址也应匹配新的控制端口。

密钥使用当前 Windows 用户的 DPAPI 加密；不放入项目文件、日志或诊断。Git、SSH、项目自身的 Python/Node 等工具仍由项目使用的电脑提供，软件自带的 Python 用于 Bridge 自身。

## 迁移与卸载

首页“导入旧版设置”选择旧项目目录，复制设置、任务记录、已结束的本机命令日志及当前用户可解密的密钥；不复制项目文件或旧版登录启动设置。本机命令记录未确认结束时拒绝导入；远端命令状态不在这项检查范围内，迁移前需另行确认已结束。目标已有设置或数据库时拒绝覆盖。导入后核对项目位置与代理，然后停止旧版后台启动，再启用软件的新后台启动；两个版本同时占用端口会报告冲突。

Windows 应用列表可以卸载。默认保留用户设置和记录；卸载时可明确选择删除软件数据。卸载只删除程序及你明确选择的软件数据目录，不遍历配置中的工作区目录；不要把项目放在软件程序或数据目录内。换电脑应重新添加当地工作区、密钥和浏览器配对，不能直接复制 DPAPI 文件。

数据目录：`%LOCALAPPDATA%\ChatAgentBridge\data`。安装目录：`%LOCALAPPDATA%\ChatAgentBridge\app`。它不更改全局 PATH，不要求管理员权限。
