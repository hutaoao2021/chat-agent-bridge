## 尚未验收

- 当前电脑没有可用 Windows Sandbox；未在完全没有宿主开发工具的干净 Windows / 新电脑验收。
- 软件新安装的真实账号 Tunnel、ChatGPT 接入与完整端到端任务由用户首次配置后验收。原源码安装的既有成功记录不替代新安装验收。
- 完整关机再开机、用户选择删除数据的卸载分支、真实 SSH 主机和项目工具链仍需现场验收。

因此此版本为预览版，不声称新电脑和账号流程已全部验收。软件不提高 ChatGPT 额度，也不保证关机/休眠期间运行。

## 实现选择

- 保留旧源码启动入口，软件使用新的配置驱动 supervisor；迁移需要显式导入和切换。
- SSH 高级配置在软件内使用经过校验的 JSON 编辑器。
- 密钥使用当前用户 DPAPI；命令仍需扩展审批；未知发送结果暂停。
