# 故障排查

先打开软件“诊断”，检查各项，再导出诊断用于反馈。导出包含版本、时间戳、组件状态、代码和说明，不含 API key、配对凭据、任务正文和项目路径。

| 状态 | 操作 |
| --- | --- |
| 设置无法读取或校验失败 | 检查原设置文件；损坏时在“连接”页“备份并重置设置”，再重新配置。目录不可用时先修正目录，保留其他连接设置 |
| 未检测到 Bridge 监听 | 首页启动；检查运行环境和配置 |
| 端口冲突 | 检查旧版后台或其他程序；修改端口并重启，不要结束不认识的进程 |
| 等待代理 | 先打开自己的代理软件，或确认该网络可以直连后清空代理设置 |
| 密钥无法解密 | 在当前 Windows 用户重新输入 Tunnel key；不能复制其他电脑的加密文件 |
| Tunnel 管理端口监听但云端未核验 | 核对 Tunnel ID、key 权限、organization/workspace 和网络；不要仅凭端口判断连接成功 |
| 扩展已更新/上下文失效 | 重新加载扩展，刷新已打开的 ChatGPT 页面 |
| 本机配对有效但码框为空 | 配对后清空码框正常；配对有效不代表云端连通 |
| 缺任务 binding | 确认当前对话已启用工作模式，刷新页面后发送新需求 |
| waiting_for_approval | 在扩展检查实际命令并批准或拒绝 |
| Could not send this ChatGPT message | 暂停，检查最后一条是否已发送，避免重复操作；手动发送恢复说明后勾选检查并人工恢复 |
| completed 且停止续接 | 任务记录已完成；核对实际结果。工作模式仍启用时，下次需求会准备新任务 |

重装或升级默认保留 `%LOCALAPPDATA%\ChatAgentBridge\data`。反馈问题请附脱敏诊断、版本、实际操作，不要上传数据目录、Tunnel profile、完整网络响应或认证 token。
